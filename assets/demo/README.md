# Commandment demo

A 64-second tour of a compiled `alienctl` application, from declaration to real
terminal output, completion, schema, and semantic tests.

- [`commandment-demo.mp4`](commandment-demo.mp4) — 1920 × 1080, 30 fps, H.264
- [`commandment-demo-720p.mp4`](commandment-demo-720p.mp4) — 1280 × 720, lighter for the web
- [`commandment-demo-poster.jpg`](commandment-demo-poster.jpg) — poster frame
- [`commandment-demo-preview.gif`](commandment-demo-preview.gif) — short terminal loop

The video is silent with on-screen captions. The terminal output is captured from
the `alienctl` example used in the README and the getting-started guide.

Source and render instructions: [`branding/video`](../../branding/video). The
storyboard and visual guidelines are in the [brand guide](../../branding/README.md#demo-storyboard).
